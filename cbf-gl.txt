How It Works

- Stays Open: Unlike a plain EXIT command which closes cmd.

exe, using /B keeps the command 
shell open.

- Returns Control: It exits the active batch file or subroutine and hands control back to the 
calling script or command line.

- Sets Error Code: You can pass an optional number (EXIT /B <exitCode>) to set the 
%ERRORLEVEL% variable for error tracking.

- Without a Number: Running EXIT /B with no number keeps the current %ERRORLEVEL% value 
intact.

              nul/2  :nul>2: In Windows command prompts and batch files, >nul 2>&1 (often typed or misremembered as 
nul>2 or >nul 2>nul) is a command-line redirection idiom used to completely silence or hide 
all output from a command.

How It Works

- >nul: Redirects standard output (stdout), which is the normal text or data a program prints, 
to the nul device (Windows' digital "bit bucket" or black hole that discards everything). It 
is shorthand for 1>nul.

- 2>&1: Redirects standard error (stderr), stream number 2, so that it goes to the exact same 
destination as stream number 1 (which is nul).

Common Variations

- >nul 2>nul: Explicitly sends both standard output and standard error to the nul device 
separately, achieving the exact same silencing result (though slightly less concise).

- 1>nul 2>nul: The explicit numeric version of the same command.
